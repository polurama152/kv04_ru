# Служебные скрипты `bin/`

Схема общая с traktoristy/polurama: разработка локально, штатная выкладка —
autoUpload PhpStorm, скрипты — контроль и фолбэк. Запускаются с рабочей
машины (Git Bash), на сервер ходят по SSH сами.

| Скрипт | Что делает |
|---|---|
| `deploy.sh` | сверка md5 кастома (`public_html/local/`, `index.php`, `.htaccess`) с продом и доставка расхождений по scp; `--check` — только сверка |
| `smoke.sh` | строго читающий смоук боевого сайта: пин-пад, форма логина админки, 404 фейковой share-ссылки, закрытость исходников, статика темы, `php -l` боевым PHP, дрейф деплоя, хвост журнала ошибок |

Зачем `deploy.sh`, если есть autoUpload: PhpStorm возит правки, только пока
IDE открыта — изменения, сделанные из CLI при закрытой IDE, на прод не
уезжают (случалось). Скрипт закрывает эту дыру и никогда не трогает ядро
Bitrix — только кастом.

Код возврата обоих — 1 при провале, годится для автоматики.

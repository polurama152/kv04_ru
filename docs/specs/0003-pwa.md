# 0003 — PWA: дневник как приложение

- Статус: `done`
- Дата: 2026-08-29
- Модуль: `kv04.diary`, `index.php`, `sw.js`

## Зачем

Дневник телефонный по природе, а целевой пользователь — админ сайта, которому
нужен быстрый вход в заметки. PWA даёт иконку на экране, standalone-окно без
адресной строки и мгновенную статику из кэша.

## Решение

- **Офлайн — только оболочка.** В Cache Storage попадает статика и страница
  «нет сети», HTML — никогда: кэшированную ленту можно было бы прочесть в
  обход пина, а приватность дороже офлайн-чтения.
- **Кэшируется только неизменяемое.** Статика и так уходит с `?v=<mtime>`
  (см. `$kv04DiaryAsset` в `index.php`), поэтому воркер кэширует cache-first
  без инвалидации: новая версия файла — это новый URL. `/upload/`, POST и
  `.php` мимо воркера.
- **Установка — системная.** Браузер сам предлагает «Добавить на экран»,
  своего UI нет. Имя под иконкой — «Дневник», полное — «Мой дневник».
  Иконка: тёмный `#0e1621`, телеграм-пузырь в акценте `#2AABEE`.
- **`sw.js` лежит в корне** — scope сервис-воркера определяется URL файла,
  из `/local/...` он накрыл бы только `/local/`.
- **Share-страница (`/d/<token>`) без PWA**: ни манифеста, ни регистрации —
  гостю по ссылке установка ни к чему.

## Вне скоупа

Офлайн-чтение ленты, push-уведомления (пригодятся мониторингу — отдельной
спекой), своя кнопка установки, periodic background sync.

## Контракт

- `/sw.js` — сервис-воркер, кэш `kv04-diary-v1`; при смене логики поднять
  суффикс — `activate` смоет старый кэш.
- `/local/modules/kv04.diary/assets/pwa/` — `manifest.webmanifest`,
  `offline.html`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`,
  `apple-touch-icon.png`.
- `index.php`: манифест и регистрация — только при пустом `?d=`.
- `.htaccess`: `Cache-Control: no-cache` на `sw.js` (обёрнуто в
  `IfModule mod_headers.c` — без модуля браузер сверяет воркер раз в сутки).

## Файлы

- `public_html/sw.js`
- `public_html/local/modules/kv04.diary/assets/pwa/`
- `public_html/index.php`, `public_html/.htaccess`
- `bin/deploy.sh` — `sw.js` добавлен в возимый кастом

## Долг

- Маркетплейс: установка модуля должна сама класть `sw.js` в корень
  (`CopyDirFiles` из `install/`), пока файл живёт в репозитории сайта.
- Push-уведомления для мониторинга — потребуют ключей VAPID и страницы
  подписки; отдельной спекой.

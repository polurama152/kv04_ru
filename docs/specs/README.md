# Спеки изменений

Короткие продуктово-технические решения. Ускоряют онбординг: не надо читать весь чат.

## Как вести

1. Новая фича → скопировать `TEMPLATE.md` в `NNNN-kebab-title.md` (следующий номер).
2. Статус `draft` → согласовать решение → `in-progress` → код → `done`.
3. Поведение изменилось — править ту же спеку, не плодить дубли.
4. Правила кодирования сюда не писать — только `.cursor/rules/`.
5. Спеки править только по явной команде пользователя.
